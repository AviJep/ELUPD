# ELUP Project

This workspace contains a frontend and a backend application.

## Backend
See `backend/README.md` for details. Install dependencies and run:

```bash
cd backend
npm install
npm run dev
```

## Frontend
The frontend is a Vite/React app. To start:

```bash
cd frontend
npm install
npm run dev
```

By default the frontend will proxy `/api` requests to the backend at
`http://localhost:3001` during development.
